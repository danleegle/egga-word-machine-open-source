# Egga 单词机简明使用教程

适用固件：Egga 2.64 及之后的同类版本。

面向普通用户，以当前固件代码中的按键逻辑和设置菜单为准。

## 1. 三十秒开始背词

全新设备第一次启动会显示欢迎页。短按确认键进入学习；这个欢迎页只出现一次，之后重启会直接回到学习页面。完整擦除设备后会再次出现。

1. 打开设备，等待电子墨水屏刷新完成；如果是欢迎页，短按确认键开始。
2. 看到单词后先在心里回忆含义。
3. 短按确认键，翻到答案背面查看释义、例句和翻译。
4. 认识：在答案背面短按确认键，记为答对并进入下一词。
5. 忘记：在答案背面短按上键，记为答错，稍后会再次出现。

默认每日目标为 20 个词。设备会优先安排该复习的旧词，再加入新词；学习进度、设置和已保存的 Wi-Fi 在断电后仍会保留。

如果只是暂时拿不准，在答案背面短按下键，可把这个词放到后面再看。它既不算答对，也不算答错。

## 2. 按键速查

| 操作 | 单词正面 | 答案背面 | 设置页 |
| --- | --- | --- | --- |
| 短按上键 | 提示先看答案 | 忘记，稍后重现 | 向上选择 |
| 短按下键 | 提示先看答案 | 模糊，稍后再看 | 向下选择 |
| 短按确认键 | 查看答案 | 答对，进入下一词 | 进入或保存 |
| 长按上键 | 上一词 | 上一词，不评价 | 向上选择 |
| 长按下键 | 下一词 | 下一词，不评价 | 向下选择 |
| 长按确认键 | 播放发音 | 播放发音 | 返回或退出 |
| 双击确认键 | 已启用 AI 教师时进入讲解 | 已启用 AI 教师时进入讲解 | 无操作 |

本地词库和墨墨模式使用同一套背词按键：短按上/确认/下分别评价忘记/认识/模糊，长按上/下浏览前后单词。长按上键或下键约 1 秒，长按确认键约 1.6 秒。

答案背面通常保留操作提示栏。遇到三条及以上释义时，设备会先把各条释义横向排列；如果排版后仍需要第三行，才会临时隐藏操作提示栏并把空间让给释义。需要重新查看按键映射时，也可以进入“设置 > 系统 > 按键说明”。

### 进入和退出设置

- 进入：在普通单词页面同时按住上键和下键，直到进入设置页。
- 移动：短按或长按上键、下键。
- 进入/保存：短按确认键。
- 返回/退出：长按确认键。若当前有弹窗，会先关闭弹窗；回到设置首页后，再长按一次即可退出。

## 3. 学习模式

| 模式 | 是否需要 Wi-Fi | 是否记录进度 | 适合场景 |
| --- | --- | --- | --- |
| 本地离线 | 不需要 | 记录 | 日常背词、按计划复习，推荐大多数用户使用 |
| 背词模式 | 不需要 | 不按复习算法记录 | 快速浏览、查词、预览词库 |
| 墨墨在线 | 首次同步需要，短时断网可继续 | 同步到墨墨 | 已配置墨墨授权的用户 |

切换路径：设置 -> 学习模式 -> 选择模式 -> 短按确认键保存。

### 墨墨在线按键

墨墨在线会从你的墨墨账号获取当前学习任务，并把“熟悉、模糊、忘记”的结果同步回墨墨。设备本地的“每日目标”不会替代墨墨自己的学习计划。

#### 第一次使用前

1. 在电脑上使用最新版 Chrome 或 Edge 打开 `https://egga-assets.pages.dev/flasher/`。
2. 唤醒单词机，用可传输数据的 USB 线连接电脑。
3. 点击网页上的“识别设备”，在浏览器弹窗中选择 `USB JTAG/serial debug unit (COMx)`，再点击“连接”。
4. 在同一网页的“Wi-Fi 账号密码设置”中写入可用 Wi-Fi。
5. 找到“墨墨账号导入”，输入手机号/邮箱和密码。
6. 如需今日任务离线快照，在墨墨 App 的“我的 -> 更多设置 -> 实验功能 -> 开放 API”申请 Token，并填入“墨墨开放 API Token”。
7. 点击“导入 / 更新认证”，再点击“读取状态”，确认在线账号和离线快照状态。认证只保存在设备内部，网页不会保留。

#### 进入墨墨在线

1. 在普通单词页面同时长按上键和下键，进入设置。
2. 选择“学习模式” -> “墨墨在线”，短按确认键保存。
3. 长按确认键退出设置页。
4. 设备会连接 Wi-Fi 并加载墨墨当前任务；如果页面还没有单词，短按确认键或下键拉取。

| 操作 | 结果 |
| --- | --- |
| 无单词时短按确认键或下键 | 拉取单词 |
| 正面短按确认键 | 显示释义 |
| 背面短按确认键 | 提交“熟悉” |
| 背面短按上键 | 提交“忘记” |
| 背面短按下键 | 提交“模糊” |
| 长按上键/下键 | 获取上一方向/下一方向的单词 |
| 长按确认键 | 播放发音 |

长按切回今天已经评价过的单词时，设备会直接显示释义，并在右上角显示当时的评价标记 `[认识]`、`[模糊]` 或 `[忘记]`。右下角仍只显示当前操作反馈。评价标记会保存在设备中，重启或网络重连后仍可恢复。

启用“AI 背词教师”后，在单词页面双击确认键进入 AI 讲解；进入后长按确认键说话，松开后发送，短按确认键可取消当前回答或退出。

墨墨在线空闲时会自动关闭 Wi-Fi 省电；再次按键时会自动尝试联网。

### 墨墨断网与离线快照

- 每次提交“熟悉、模糊、忘记”前，设备都会先把答案写入本地；断网或重启不会直接丢失这次操作。
- 配置开放 API Token 后，设备联网时会先初始化 WebStudy，再按账号实际任务下载当天未完成单词，不要求用户当天先打开墨墨 App。单次最多 1000 个（墨墨开放 API 上限）。已经在线加载过的单词会缓存完整卡片；能在当前本地词库中匹配的单词会直接读取本地释义，其他单词离线时只显示拼写并提示联网加载详情。开放 API 仍处于公测期；请求暂时失败时设备会保留已有的当天快照，不会清空待同步答案。
- 断网时可以继续翻面、记录答案以及浏览今日快照。屏幕会显示“离线记录待同步”。
- 重连后设备按顺序核对墨墨当前单词。开放 API 与 WebStudy 使用不同格式的单词 ID；设备只有在服务器当前词与离线记录的拼写唯一一致时才映射 WebStudy ID 并上传答案。如果 App、网页或另一台设备已经改变学习进度，本机记录会进入冲突列表，不会强行覆盖服务器进度。
- 在线刷机页“读取状态”会显示今日快照数量、待同步数量和冲突数量。冲突记录仅用于提示和排查，不会自动上传。

如果屏幕提示“未导入墨墨认证”，请重新打开线上刷机页面，识别设备并导入账号密码。如果提示墨墨今日任务已完成，需要先在墨墨 App 或网页端增加任务，再回到设备同步。

## 4. 发音、词库和每日目标

### 发音

- 手动播放：在单词页面长按确认键。
- 自动发音：设置 -> 自动发音。开启后，翻到答案背面时自动播放。
- 发音口音：设置 -> 发音口音，可在美音和英音之间切换。
- 调整音量：设置 -> 音量。
- 本地没有对应音频时，设备会尝试联网获取发音。

### 词库

- 切换已安装词库：设置 -> 背诵词库。
- 下载或删除在线词库：连接 Wi-Fi 后进入设置 -> 我的词库。
- 设备会分别保存不同词库的学习进度，正常切换不会清空原来的记录。
- 新版进度按单词稳定标识保存；词库重新排序后，会尽量把原进度匹配回同一个单词。

### 每日目标和显示

- 设置 -> 每日目标：可设置 5 到 200 个词，每次调整 5 个。
- 设置 -> 背诵顺序：选择顺序或随机。
- 设置 -> 显示字体：选择清晰大字或紧凑小字。
- 今日完成数会在 RTC 日期变化后自动归零；设备跨夜保持运行或从浅睡眠唤醒也会立即生成新一天的复习队列，单词的长期复习状态不会被清空。
- 顶部状态栏常驻显示设备时间（`HH:MM`），按键、唤醒和其他页面操作会同步局部刷新。联网后设备会自动校准时间；若显示 `--:--`，说明 RTC 尚未获得可信时间，需要连接一次 Wi-Fi 完成校时。
- 设置 -> 自动休眠：可选择 30 分钟、1 小时、3 小时、6 小时或永不；默认 3 小时。“永不”会增加耗电。

## 5. Wi-Fi 配网

本地离线背词、背词模式和切换已下载词库不需要联网。下载词库、在线发音、系统升级和墨墨在线模式需要 Wi-Fi。

设备达到“自动休眠”设置的无操作时间后会进入浅睡眠；按任意学习按键可唤醒并继续使用。修改时长后会从本次操作重新计时。

### 配网步骤

1. 同时长按上键和下键进入设置。
2. 移动到 Wi-Fi 配网，短按确认键。
3. 手机打开 Wi-Fi 设置，连接屏幕显示的 `Egga-xxxx` 热点。
4. 手机提示“此网络无法上网”时，选择继续连接。
5. 配网页若未自动弹出，请在浏览器打开 `http://192.168.4.1`。
6. 选择家里的 Wi-Fi，输入密码并提交，等待设备保存并连接。

建议使用 2.4GHz 普通密码 Wi-Fi。5GHz-only、隐藏网络、校园网和企业认证网络可能无法连接。

设备会保存网络。只有更换路由器、修改 Wi-Fi 密码或清空设备存储后，通常才需要重新配网。

## 6. 系统升级

1. 确认设备已连接 Wi-Fi，并保持电量充足。
2. 进入设置 -> 系统升级。
3. 短按确认键检查并安装新版本。
4. 升级期间不要关机或断电，等待设备自动完成并重启。

## 7. 在线刷机与设备维护

线上地址：`https://egga-assets.pages.dev/flasher/`

请在电脑端使用最新版 Chrome 或 Edge。手机浏览器、微信内置浏览器、Safari 和 Firefox 通常无法使用 Web Serial。

### 识别设备

1. 唤醒单词机，用可传输数据的 USB 线连接电脑。
2. 打开线上刷机页面，点击“识别设备”。
3. 在浏览器弹窗中选择 `USB JTAG/serial debug unit (COMx)`。
4. 点击“连接”，等待网页显示已识别的 Egga 设备和当前版本。

如果列表中没有设备，先更换 USB 数据线或 USB 接口。只能充电、不能传输数据的线无法识别设备。

### 普通刷机和强制刷机

| 方式 | 适合情况 | 会写入的内容 |
| --- | --- | --- |
| 普通刷机 | 设备能正常识别，已有 Egga bootloader 和分区表 | OTA 初始数据和应用固件 |
| 强制刷机 | 首次完整安装、设备异常、普通刷机失败或售后要求 | bootloader、分区表、OTA 初始数据和应用固件 |

### 强制刷机步骤

1. 在“固件版本”中选择最新稳定版本。网页会自动读取线上版本。
2. 点击“强制刷机”，确认开始。
3. 刷机过程中不要关闭网页、拔掉数据线或让电脑休眠。
4. 耐心等待进度达到 100%，通常需要约 3-5 分钟。
5. 显示刷机完成后，再点击一次“识别设备”，确认设备名称和固件版本。
6. 如仍有问题，复制网页底部“日志”中的内容并发送给售后。

刷机页面还可以在识别设备后直接写入 Wi-Fi、导入墨墨账号和管理设备资源，不再需要安装 Egga 桌面客户端。

### 导入 Anki 或自定义本地词库

1. 使用桌面版 Chrome 或 Edge 打开刷机页面，并选择“Egga 单词机”。
2. 没有现成文件时，点击“下载自定义词库模板”，使用 Excel 或 WPS 填写。单词和释义必填，音标、例句、例句翻译可以留空。
3. 选择填写后的 CSV 文件；也可以选择 Anki `.apkg`、TSV 或 TXT 文件。
4. `.apkg` 文件需要选择卡片类型，并确认单词、释义、音标和例句的字段映射。
5. 点击“检查词库”，确认名称、词数和文件大小；再点击“连接设备并写入”，选择 Egga 的 USB 串口。
6. 写入成功后设备会自动重启。进入“设置 -> 本地词库”即可选择新词库，学习进度保存在设备本地。

导入过程完全在浏览器本地完成，只写入用户当次选择的 USB 设备，不会上传到服务器，也不会出现在公共词书列表。网页和固件会分别检查文件编码、必填列、五列结构、字段长度、总大小、分块偏移和 SHA-256；失败时不会激活不完整文件。当前版本导入卡片内容后使用 Egga 本地复习计划，不会把学习进度同步回 Anki。复杂卡片模板、图片遮挡和任意脚本不会在设备上执行。

## 8. 常见问题

### 为什么答错的词又出现了？

这是正常复习安排。答错后，单词会被放回队列，稍后再次巩固。

### 今日目标完成后还能继续吗？

可以在设置里提高每日目标，或切换到背词模式继续浏览。

### 手机连上 Egga 热点却打不开网页？

先选择继续连接该热点，必要时临时关闭手机移动数据，再在浏览器手动输入 `http://192.168.4.1`。

### 长按确认键没有发音？

先检查音量和电量。本地没有该词音频时，需要连接 Wi-Fi 才能尝试在线发音。

### 设备放久后屏幕还显示原内容，是不是没关机？

电子墨水屏断电也能保留画面。设备久置会自动进入省电状态，按任意学习键后稍等片刻即可继续。

### 仍然无法解决怎么办？

请记录屏幕提示、当前学习模式和出现问题前的操作步骤，再联系售后。
